# 📊 Dashboard de Vendas por Região (Python + Streamlit)

Projeto de análise de dados com foco em diagnóstico e visualização de performance comercial por região.

## 🚀 Tecnologias
- Python
- Pandas
- Streamlit
- Plotly

## 📊 O que o dashboard mostra

- Faturamento por zona
- Ranking de lojas
- Distribuição por canal (Delivery vs Loja Física)
- Formas de pagamento
- Evolução diária de vendas
- KPIs estratégicos (Ticket Médio, Volume, etc)

## 🎯 Objetivo

Simular um cenário real de negócio para análise de performance e tomada de decisão.
